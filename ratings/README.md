# Ratings

Students' ratings of the review cases, one file per rater per download, as saved by the workbench (`bench.html` → Review cases → Download ratings), e.g. `ratings-mj-2026-10-14.json`. Raters go by their initials, not their names: this folder is in the public repo. Load them all in the same tab ("Load ratings…") to see what's most often wrong. See `RECOMMENDATIONS.md`, part C.

Kept in the repo, never deployed (`firebase.json` ignores this folder).
